This asset catalog now covers iOS/iPadOS/visionOS only. The `mac` idiom entry that used to live here (a placeholder reusing the light iOS artwork, since the traditional asset catalog `mac` idiom has no Any/Dark support) has been removed — macOS gets its own real Any/Dark icon from `Passata/AppIconMac.icon`, an Icon Composer document, wired in via the macOS-only `ASSETCATALOG_COMPILER_APPICON_NAME` override in the project's build settings. Both reuse the same two source PNGs.
