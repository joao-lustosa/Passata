This appiconset is retired and inert — renamed from `AppIcon.appiconset` to `AppIconLegacyFlat.appiconset` specifically so it stops claiming the `AppIcon` asset-catalog name, since that name now belongs to `Passata/AppIcon.icon`, an Icon Composer document with real separated layers (design review item 4.4). Kept here, not deleted, as a fallback reference until the new icon is fully proven out — matches `design/AppIconRenderer/`, the flat-PNG rendering pipeline this appiconset's two source images came from, which is being kept untouched for the same reason. Nothing in the project references this folder; it is not compiled into any target's app icon.

Prior history: macOS was the first platform moved off this appiconset, to its own real Any/Dark icon at `Passata/AppIconMac.icon`, wired in via the macOS-only `ASSETCATALOG_COMPILER_APPICON_NAME` override. iOS/iPadOS (this appiconset's last remaining consumer) has now moved too. All three `.icon` documents (`AppIconMac.icon`, `AppIcon.icon`) trace back to the same source artwork as the two PNGs still sitting in this folder.
